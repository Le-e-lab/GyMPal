# Military-Inspired Core Workout Plan for GyMPal

## Overview
This plan combines military-grade core training with GyMPal's existing structure to help build a strong, sporty core while combating procrastination through consistent daily scheduling.

## Weekly Schedule (Integrated with GyMPal)

### Monday - Strength A (Full Body + Core Focus)
- **Warm-up**: 5 min jump rope or jumping jacks
- **Main Workout**:
  - Push-ups: 4x15 (standard or decline for progression)
  - Dumbbell Rows: 4x12 each arm
  - Goblet Squats: 4x15
  - Pike Push-ups: 3x12
  - **CORE CIRCUIT** (3 rounds, 45s work/15s rest):
    - Forearm Plank
    - Bicycle Crunches
    - Mountain Climbers
    - Russian Twists
    - Hollow Hold
- **Cool-down**: 5 min stretching + deep breathing

### Tuesday - Run Day (Easy) + Core Finisher
- **Run**: 4-5km easy pace (or walk/run intervals if needed)
- **Post-Run Core** (3 rounds):
  - Plank: 60s
  - Side Plank: 30s each side
  - Leg Raises: 15 reps
  - Flutter Kicks: 30s
  - V-Ups: 12 reps

### Wednesday - Strength B (Lower + Core Focus)
- **Warm-up**: 5 min dynamic stretching
- **Main Workout**:
  - Goblet Squats: 4x15
  - Dumbbell RDLs: 3x12
  - Walking Lunges: 3x20 steps (10 each leg)
  - Calf Raises: 4x20
  - **CORE CIRCUIT** (3 rounds):
    - Russian Twists: 20 reps
    - Leg Raises: 15 reps
    - Plank to Push-up: 10 reps
    - Side Plank Hip Dips: 12 each side
    - Dead Bug: 15 reps each side

### Thursday - Run Day (Intervals) + Core
- **Run**: Interval training
  - Warm-up: 1km easy jog
  - 6x 400m hard effort with 200m walk recovery
  - Cool-down: 1km easy jog
- **Post-Run Core** (same as Tuesday)

### Friday - Strength C (Upper + Conditioning + Core)
- **Warm-up**: 5 min arm circles, shoulder dislocates
- **Main Workout**:
  - Push-ups: 4x20 (or weighted if possible)
  - Dumbbell Press: 3x12
  - Farmers Walk: 3x40 steps (heavy dumbbells)
  - Tricep Dips: 3x15
  - **CORE FINISHER** (3 rounds for time):
    - 30s Plank
    - 20 Bicycle Crunches
    - 15 Leg Raises
    - 20 Russian Twists
    - 30s Rest

### Saturday - Long Run Day + Core Maintenance
- **Long Run**: 8-10km easy pace (capped until 75kg goal)
- **Post-Run Core** (maintenance):
  - Plank: 3x max hold (aim for 60s+ each)
  - Side Plank: 2x30s each side
  - Bird-Dog: 3x12 each side

### Sunday - Active Recovery
- **Activity**: 30-45 min walk or light hiking
- **Mobility Work**:
  - Cat-Cow: 2x10
  - Child's Pose: 2x30s
  - Seated Forward Fold: 2x30s
  - Supine Twist: 2x30s each side
  - Deep Breathing: 5min

## Daily Procrastination-Busting Routine (5-Minute Morning Core)
Do this immediately upon waking to build consistency:
1. Forearm Plank - 45s
2. Bicycle Crunches - 30s
3. Mountain Climbers - 30s
4. Russian Twists - 30s
5. Hollow Hold - 30s
6. Rest 15s
Repeat 2x

## Progression System
- **Weeks 1-4**: Focus on form and consistency
- **Weeks 5-8**: Increase duration/reps by 25%
- **Weeks 9-12**: Add intensity (weighted planks, decline positions)
- **After 12 weeks**: Reassess and adjust based on 75kg goal achievement

## Equipment Needed (Minimal)
- Exercise mat
- Dumbbells (light to moderate set)
- Timer/stopwatch (phone works)
- Water bottle

## Integration with GyMPal Features
1. **Daily Check-ins**: Use GyMPal to log completion of morning 5-minute routine
2. **Workout Tracking**: Log main workouts in GyMPal's custom workout builder
3. **Progress Photos**: Take weekly photos to track core development
4. **Streak Building**: Use GyMPal's streak counter to maintain daily habit
5. **Audio Cues**: Enable timer alerts for interval training

## Expected Outcomes (12 Weeks)
- Significantly improved core strength and stability
- Better posture and reduced back pain
- Enhanced athletic performance in running and other activities
- Increased mental discipline and reduced procrastination
- Visible abdominal definition (with proper nutrition)
- Improved endurance and overall fitness

## Notes
- Listen to your body - modify intensity as needed
- Proper nutrition is crucial for visible results
- Consistency beats intensity - aim for daily completion
- The morning 5-minute routine is the anchor habit
- Adjust running distances based on current fitness level
