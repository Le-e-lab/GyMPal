# GyMPal: Daily Planner + Dumbbell Workout Overhaul

## Problem

GyMPal tracks **whether** you worked out but not **what you actually lifted**. The exercise library is 90% bodyweight — dumbbells are referenced in workoutData.js but not in the selectable library. There's no per-exercise set/rep/weight logging, no progressive overload tracking, no calendar view, and no daily planner beyond "complete today's mission."

Compared to Strong, Hevy, and LiftShift, GyMPal is missing the core features that make a workout tracker actually useful.

## Phase 2: Per-Exercise Set/Rep/Weight Logging

**Goal:** Let users log actual weight and reps per exercise during a workout — the #1 missing feature.

**Files to modify:**
- `src/hooks/useWorkout.js` — add `logExerciseSet(exerciseId, setIndex, weight, reps)` function, new localStorage key `gympal_exercise_logs`
- `src/components/WorkoutCard.jsx` — add expandable set/rep/weight input rows under each exercise checkbox
- `src/components/Dashboard.jsx` — pass new props down

**Data model:**
```js
// localStorage key: gympal_exercise_logs
{
  "2026-06-17": [
    {
      exerciseId: "db-bench-press",
      sets: [
        { weight: 15, reps: 10 },
        { weight: 15, reps: 10 },
        { weight: 17.5, reps: 8 }
      ]
    }
  ]
}
```

**UI changes to WorkoutCard:**
- Each exercise row becomes expandable (tap to reveal set inputs)
- Default 3 sets with weight (kg) and reps inputs
- "+" button to add more sets
- Quick-add common weights (5, 10, 15, 20, 25 kg)
- Total volume displayed (weight x reps x sets)

## Phase 3: Workout Templates / Routine Builder

**Goal:** Let users save, name, and load custom workout routines. This replaces the hardcoded weekly split.

**Files to create:**
- `src/components/WorkoutTemplateManager.jsx` — UI for creating/editing/saving templates
- `src/hooks/useTemplates.js` — hook for template CRUD with localStorage

**Files to modify:**
- `src/components/Dashboard.jsx` — add "Templates" tab, allow selecting a template for today
- `src/components/WorkoutCard.jsx` — support loading from template data

**Data model:**
```js
// localStorage key: gympal_templates
[
  {
    id: "upper-lower-a",
    name: "Upper Body A",
    exercises: [
      { exerciseId: "db-bench-press", sets: 4, reps: 8, targetWeight: 17.5 },
      { exerciseId: "db-bent-over-row", sets: 4, reps: 8, targetWeight: 20 },
      ...
    ]
  }
]
```

**Pre-built templates to ship:**
1. Dumbbell-Only (5-day split) — the primary template
2. Full Body (3-day split) — minimal equipment
3. The existing GyMPal program (as a template)

## Phase 4: Daily Planner / Habit Tracker

**Goal:** Combine workout tracking with daily habit tracking — water, sleep, stretching, meals, etc.

**Files to create:**
- `src/components/DailyPlanner.jsx` — daily checklist of habits with streaks
- `src/hooks/useHabits.js` — hook for habit CRUD and streak tracking
- `src/data/defaultHabits.js` — default habit definitions

**Files to modify:**
- `src/components/Dashboard.jsx` — add "Planner" tab

**Features:**
- Pre-defined habits: protein (existing), water (8 glasses), sleep (7.5h target), meals (3 per day), stretching (1 session)
- Custom habit creation (name, icon, frequency)
- Per-habit streak tracking (separate from workout streak)
- Daily completion percentage ring
- Calendar heatmap showing habit completion over time

**Data model:**
```js
// localStorage key: gympal_habits
{
  habits: [
    { id: "water", name: "Water", icon: "💧", target: 8, unit: "glasses", frequency: "daily" },
    { id: "sleep", name: "Sleep", icon: "😴", target: 7.5, unit: "hours", frequency: "daily" },
    { id: "meals", name: "Meals", icon: "🍽️", target: 3, unit: "meals", frequency: "daily" },
    { id: "stretch", name: "Stretching", icon: "🧘", target: 1, unit: "sessions", frequency: "daily" },
    { id: "protein", name: "Protein", icon: "🥩", target: 130, unit: "grams", frequency: "daily" }
  ],
  logs: {
    "2026-06-17": { water: 6, sleep: 7, meals: 2, stretch: 1, protein: 125 }
  }
}
```

## Phase 5: Progressive Overload & PR Tracking

**Goal:** Auto-detect personal records and suggest next weights based on history.

**Files to modify:**
- `src/hooks/useWorkout.js` — add PR detection logic, `getExerciseHistory(exerciseId)`, `getPR(exerciseId)`
- `src/components/WorkoutCard.jsx` — show PR badges, suggest next weight
- `src/components/ProgressOverview.jsx` — add per-exercise charts using Recharts

**Logic:**
- PR = highest weight lifted for an exercise (or highest volume: weight x reps x sets)
- When user opens an exercise, show: "Last: 17.5kg x 10 | PR: 20kg x 8 | Suggest: 17.5kg x 12 or 20kg x 6"
- PR celebration toast/banner when detected during logging

## Implementation Order

| Phase | Effort | Impact | Dependencies |
|-------|--------|--------|-------------|
| 1. Dumbbell Library | Low | High | None |
| 2. Set/Rep/Weight Logging | Medium | Critical | Phase 1 (needs exercises to log) |
| 3. Workout Templates | Medium | High | Phase 2 (templates use logged data) |
| 4. Daily Planner | Medium | High | None (independent) |
| 5. Progressive Overload & PRs | Medium | High | Phase 2 (needs logged data) |
| 6. Calendar View | Low | Medium | Phase 2 + 4 (needs data to show) |

**Recommended sprint order:**
1. Phase 1 + Phase 4 in parallel (independent)
2. Phase 2 (builds on Phase 1)
3. Phase 3 + Phase 5 in parallel (both build on Phase 2)
4. Phase 6 (integrates everything)
